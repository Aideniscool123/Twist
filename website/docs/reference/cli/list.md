# twist list

```text
twist list
```

Prints a table of every instruction, grouped by category:

```text
CODE  NAME               CATEGORY  EXAMPLE
ps1   Print String       output    ps1 "Hello, reef!"
ad3   Announce Digit     output    ad3 #0
sy1   Say Yonder         output    sy1 "Loading... "
mo1   Mood Out           output    mo1
ad2   Ask Directly       input     ad2 #1
rd3   Read Dialogue      input     rd3 #2
ps3   Plant Seed         memory    ps3 #0 10
...
rv1   Reverse Vibes      chaos     rv1
ty1   Thank You          chaos     ty1
hl2   Hang Loose         misc      hl2
```

The same list is on the [instruction reference](/docs/reference/instructions)
page, with a full page for every instruction.
