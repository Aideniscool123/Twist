# Credits

**Twist** was created by **Aiden** ([@Aideniscool123](https://github.com/Aideniscool123)).

## How it was built

- **Phase 1 (design):** the language rules and first ten instructions were
  designed with the help of Claude, in a chat, and set up by Aiden.
- **Phases 2-9 (instruction set, lexer, parser, interpreter, control flow,
  chaos, CLI, REPL, playground and docs):** written by **Claude Code**, an AI
  coding assistant, working from Aiden's design decisions: maximum chaos,
  dice, Swap Words, Reverse Vibes, moods, decimals, lists, fully sarcastic
  errors, and a fancy playground with dark and light themes.
- **This website:** built with [Docusaurus](https://docusaurus.io), set up by
  Aiden and written by Claude Code.

## Built with

- [Node.js](https://nodejs.org): no other dependencies for Twist itself
- [Docusaurus](https://docusaurus.io): this site
- [docusaurus-search-local](https://github.com/easyops-cn/docusaurus-search-local): search
- [JetBrains Mono](https://www.jetbrains.com/lp/mono/) and
  [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk): fonts
