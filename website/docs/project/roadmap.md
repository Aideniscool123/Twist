# Roadmap

| Phase | What | Status |
| --- | --- | --- |
| 1 | Design the language rules and first instructions | ✅ Done |
| 2 | Finish the instruction set (make it Turing complete) | ✅ Done |
| 3 | Build the lexer and parser | ✅ Done |
| 4 | Build the core interpreter (hello world) | ✅ Done |
| 5 | Add control flow (labels, jumps, loops, call/return) | ✅ Done |
| 6 | Add strings, lists, and the weird instructions | ✅ Done |
| 7 | Add error messages, tests, and the `run` CLI/REPL | ✅ Done |
| 8 | Build the web playground | ✅ Done |
| 9 | Write docs and an example gallery | ✅ Done |
| 10 | Build something real with Twist | 🔜 Next |

The [dev log](/blog) has a post for each phase.

## Ideas for later

- A Twist program that's actually useful (Phase 10).
- More chaos: an instruction that renumbers cells, or one that only works on
  Tuesdays.
- An editor extension with Twist highlighting.
- Sharing playground programs with short links.
