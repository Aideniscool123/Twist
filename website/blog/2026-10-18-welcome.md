Twist has a website.

<!-- truncate -->

It has a [tutorial](/docs/tutorial/hello), a
[language guide](/docs/language), a page for
[every instruction](/docs/reference/instructions) and
[every example](/docs/examples), the [playground](pathname:///play/playground/),
and this dev log.

Some things worth knowing about how it's built:

- **The instruction and example pages are generated** from Twist's own
  source, so they can't go out of date. Every example shows its real output.
- **Every code sample is tested.** A test runs each Twist snippet on the site
  and checks it prints what the page says.
- **No server.** It's plain files on GitHub Pages, rebuilt automatically
  whenever `main` changes.
