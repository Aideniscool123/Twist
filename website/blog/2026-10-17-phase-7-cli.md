```text
bad.twist:2: Unknown instruction ps9. Did you just make that up?
bad.twist:3: Label @nowhere is never defined. Jumping into the void, are we?
```

- **Sarcastic errors:** every error keeps the useful part first, then gets a
  remark that fits the mistake.
- **`twist run`** with `--calm`, `--seed` and `--max-steps`. Remarks go to
  stderr, so they never mix with program output.
- **`twist repl`:** type a line, it runs.

One real bug turned up: PowerShell and Notepad add an invisible byte-order
mark to the start of text, and Twist choked on it. Now it's ignored.

246 tests passing. About 3 minutes.
